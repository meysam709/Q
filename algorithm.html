1. Algorithm Analysis & Big‑O

Measuring an algorithm’s efficiency uses time complexity (how fast) and space complexity (memory).

Asymptotic Notations

  • Big O (O) – upper bound (worst‑case)
  • Big Omega (Ω) – lower bound (best‑case)
  • Big Theta (Θ) – tight bound (average‑case)

Common Complexities (in order of growth)

2. Sorting Algorithms

Comparison‑based sorts

Bubble Sort

Repeatedly swap adjacent elements if wrong order. O(n²) time, O(1) space. Stable.

def bubble_sort(arr):
    for i in range(len(arr)):
        for j in range(0, len(arr) - i - 1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]

Selection Sort

Find min element, swap with first; repeat. O(n²) time, O(1) space. Not stable.

def selection_sort(arr):
    for i in range(len(arr)):
        min_idx = i
        for j in range(i+1, len(arr)):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]

Insertion Sort

Build sorted array one element at a time. O(n²) time, but O(n) on nearly sorted. O(1) space. Stable.

def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key

Merge Sort

Divide & conquer. O(n log n) time, O(n) space. Stable.

def merge_sort(arr):
    if len(arr) <= 1: return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

Quick Sort

Pivot partitioning. O(n log n) average, O(n²) worst. O(log n) space (recursion). Not stable.

def quick_sort(arr, low, high):
    if low < high:
        pivot = partition(arr, low, high)
        quick_sort(arr, low, pivot-1)
        quick_sort(arr, pivot+1, high)

Heap Sort

Build max‑heap, repeatedly extract max. O(n log n) time, O(1) space. Not stable.

import heapq
def heap_sort(arr):
    heapq.heapify(arr)
    return [heapq.heappop(arr) for _ in range(len(arr))]

Non‑comparison sorts (integer keys)

  • Counting Sort – O(n + k), stable, good for small range
  • Radix Sort – O(d·(n+b)), sorts digit by digit
  • Bucket Sort – uniform distribution, average O(n + k)

3. Searching Algorithms

Linear Search

O(n) time, O(1) space. Works on unsorted data.

Binary Search

Requires sorted array. O(log n) time, O(1) space (iterative).

def binary_search(arr, target):
    l, r = 0, len(arr) - 1
    while l <= r:
        m = (l + r) // 2
        if arr[m] == target: return m
        elif arr[m] < target: l = m + 1
        else: r = m - 1
    return -1

Interpolation Search

Improved binary search for uniformly distributed data. O(log log n) average.

4. Arrays & Linked Lists

Arrays

Contiguous memory, O(1) random access. Insert/delete at end O(1) amortized, middle O(n).

Linked List

Nodes with data + pointer. Singly: one direction. Doubly: previous + next. Circular.

  • Access by index: O(n)
  • Insert/delete at head: O(1)
  • Insert/delete at tail: O(n) singly, O(1) doubly
  • No wasted capacity, but more memory per element (pointers)
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

5. Stacks & Queues

Stack (LIFO)

Push/pop O(1). Used for function calls, undo, expression evaluation.

stack = []
stack.append(1)   # push
stack.pop()        # pop

Queue (FIFO)

Enqueue/dequeue O(1). BFS, scheduling.

from collections import deque
q = deque()
q.append(1)       # enqueue
q.popleft()      # dequeue

Deque (Double‑ended queue)

Insert/delete at both ends O(1). Used for sliding window maximum.

Priority Queue (Heap)

Min‑heap / max‑heap. Insert O(log n), extract min O(log n). Implemented via heapq.

6. Hash Tables (Dictionaries)

Key → value mapping via hash function. Average O(1) for search/insert/delete. Worst O(n) due to collisions.

  • Hash function maps key to bucket index
  • Collision resolution: chaining (linked list) or open addressing (linear probing, quadratic probing, double hashing)
  • Load factor: entries / buckets. Resize when exceeding threshold (e.g., 0.75)
hashmap = {}          # Python dict
hashmap['key'] = 42

7. Trees

Binary Tree Basics

Each node has up to 2 children. Full: 0 or 2 children. Complete: all levels filled except possibly last, left‑filled. Perfect: all internal nodes have 2 children, leaves at same level.

Binary Search Tree (BST)

Left subtree ≤ node < right subtree. O(h) operations, h = height. Balanced (AVL, Red‑Black) → O(log n).

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

Tree Traversals

  • In‑order: left → root → right (sorted for BST)
  • Pre‑order: root → left → right (copy, prefix)
  • Post‑order: left → right → root (delete, postfix)
  • Level‑order: BFS using queue

Balanced Trees

  • AVL Tree: strictly balanced (|BF| ≤ 1), rotations after insert/delete
  • Red‑Black Tree: looser balance, faster insertions; used in many languages
  • B‑Tree: multi‑way search tree, used in databases/file systems; all leaves at same depth

8. Heaps

A binary heap is a complete binary tree satisfying the heap property: min‑heap (parent ≤ children), max‑heap (parent ≥ children).

  • Insert: O(log n)
  • Extract min/max: O(log n)
  • Peek: O(1)
  • Build heap: O(n)
import heapq
heap = []
heapq.heappush(heap, 5)
heapq.heappush(heap, 1)
print(heapq.heappop(heap))  # 1

Priority queue = heap. Heap sort: build max‑heap → repeated extract.

9. Graphs

A graph G = (V, E). Directed (one‑way) or undirected. Weighted edges.

Representations

  • Adjacency Matrix – O(V²) space, O(1) edge check
  • Adjacency List – O(V + E) space, faster for sparse graphs
graph = {}  # adjacency list
graph['A'] = [('B', 5), ('C', 2)]  # weighted edges

Traversals

  • BFS (Breadth‑First Search) – O(V+E), queue, shortest path (unweighted)
  • DFS (Depth‑First Search) – O(V+E), recursion/stack, cycles, topological sort, connected components
def bfs(graph, start):
    visited = set()
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            queue.extend(graph[node])
    return visited

Shortest Path

  • Dijkstra – O((V+E) log V) using heap, non‑negative weights only
  • Bellman‑Ford – O(VE), handles negative weights, detects negative cycles
  • Floyd‑Warshall – O(V³), all‑pairs shortest path, dynamic programming

Minimum Spanning Tree

  • Kruskal – O(E log E), sorts edges, union‑find
  • Prim – O(E log V), grows tree from a start node

Topological Sort

Linear ordering of DAG vertices. DFS post‑order or Kahn's algorithm (in‑degree).

Union‑Find (Disjoint Set)

Quickly detect cycles in Kruskal. Path compression + union by rank: nearly O(1) per operation.

10. Dynamic Programming

Break problem into overlapping subproblems, store results. Two approaches:

  • Top‑down (memoization) – recursion + cache
  • Bottom‑up (tabulation) – iterative array filling

Classic problems

Fibonacci

def fib(n, memo={}):
    if n <= 1: return n
    if n not in memo:
        memo[n] = fib(n-1) + fib(n-2)
    return memo[n]

Knapsack 0/1

dp[i][w] = max(dp[i‑1][w], dp[i‑1][w‑wt[i]] + val[i])

Longest Common Subsequence

dp[i][j] from dp[i‑1][j‑1] +1 if match, else max(dp[i‑1][j], dp[i][j‑1])

Coin Change

Minimum coins or number of ways. dp[amount] = min(dp[amount - coin] + 1).

11. Algorithmic Paradigms

Greedy

Make locally optimal choice at each step. Works for matroid problems. Examples: activity selection, Huffman coding, Prim's/Kruskal's.

Divide & Conquer

Break into sub‑problems, solve recursively, combine. Examples: merge sort, quick sort, binary search, Strassen's matrix multiplication.

Backtracking

Explore all possibilities, prune branches. Examples: N‑Queens, Sudoku, subset sum.

Branch & Bound

Like backtracking with bounds to skip suboptimal branches. Used for optimization (TSP).

12. Tries (Prefix Trees)

Tree‑based data structure for strings. Each node represents a character. Fast prefix‑based operations: insert, search, delete – O(m) where m = word length.

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

Applications: autocomplete, spell checker, IP routing (longest prefix match).

13. Advanced Data Structures

Segment Tree

Range queries (sum, min, max) and point updates in O(log n). Lazy propagation for range updates.

Fenwick Tree (BIT)

Prefix sums and point updates O(log n). Less memory than segment tree.

Disjoint Set Union (DSU)

Union‑find with path compression. O(α(n)) per operation.

LRU Cache

Hash map + doubly linked list. O(1) get/put.

  • Z‑Algorithm – O(n+m) pattern matching

16. Common Problem‑Solving Patterns

Sliding Window

Maintain a window over contiguous data. Optimize O(n²) to O(n). Example: max subarray sum, longest substring without repeating chars.

Two Pointers

Use two indices to traverse an array from ends or at different speeds. Sorted array problems, pair sum, palindrome check.

Fast & Slow Pointers

Floyd's cycle detection in linked list, middle of list.

Merge Intervals

Sort by start time, then merge overlapping intervals.

Binary Search on Answer

When search space is monotonic, binary search the possible answer value.

Top‑K Elements

Use heap of size K to find K largest/smallest/frequent elements.

17. Bit Manipulation Tricks

  • Get bit: (num >> i) & 1
  • Set bit: num | (1 << i)
  • Clear bit: num & ~(1 << i)
  • Toggle bit: num ^ (1 << i)
  • Check power of two: n > 0 and (n & (n-1)) == 0
  • Count set bits: Brian Kernighan's algorithm O(k) where k = number of 1s

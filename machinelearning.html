1. ML Fundamentals

Machine Learning (ML) is a subset of AI that enables systems to learn from data without explicit programming. It automates analytical model building.

Types of ML

  • Supervised – labeled data (classification, regression)
  • Unsupervised – unlabeled data (clustering, dimensionality reduction)
  • Semi‑supervised – mix of labeled and unlabeled
  • Reinforcement – agent learns via rewards/punishments

Key terminology

  • Features (X) – input variables
  • Labels (y) – target variable (supervised)
  • Training / Validation / Test – data splits
  • Overfitting – model memorizes noise
  • Underfitting – too simple to capture pattern
  • Bias / Variance trade‑off

Common steps

  1. Data collection & preprocessing
  2. Feature engineering & selection
  3. Model selection & training
  4. Hyperparameter tuning
  5. Evaluation & deployment

2. Data Preprocessing

Clean, transform, and prepare raw data for modeling.

Handling missing values

  • Delete rows/columns
  • Impute (mean, median, mode, KNN, regression)
  • Use algorithms that handle NaN (XGBoost)

Encoding categoricals

  • One‑Hot Encoding (nominal)
  • Label Encoding (ordinal)
  • Target Encoding (mean target per category)

Feature scaling

  • Standardization (z‑score): (x - μ) / σ
  • Normalization (min‑max): (x - min) / (max - min)
  • Important for SVM, KNN, Neural Networks

Outlier detection

  • Z‑score, IQR, Isolation Forest, DBSCAN
  • Cap / floor values
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer

# Impute missing values
imputer = SimpleImputer(strategy='median')
X_train = imputer.fit_transform(X_train)

# Scale features
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)

3. Regression Algorithms

Predict continuous target values.

Linear Regression

y = w·x + b. Minimizes MSE. Assumes linearity, no multicollinearity.

from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X_train, y_train)

Ridge Regression

Adds L2 penalty (λ·Σw²) to reduce overfitting. Shrinks coefficients.

from sklearn.linear_model import Ridge
model = Ridge(alpha=1.0)

Lasso Regression

L1 penalty (λ·Σ|w|). Performs feature selection by driving some coefficients to zero.

from sklearn.linear_model import Lasso
model = Lasso(alpha=0.1)

ElasticNet

Combines L1 & L2. α controls weight between them.

from sklearn.linear_model import ElasticNet

Evaluation metrics for regression: MSE, RMSE, MAE, R². Use cross‑validation to get reliable estimates.

4. Classification Algorithms

Predict discrete class labels.

Logistic Regression

Despite the name, used for classification. Outputs probabilities via sigmoid. Regularization (L1/L2) available.

from sklearn.linear_model import LogisticRegression
model = LogisticRegression(C=1.0)
model.fit(X_train, y_train)

K‑Nearest Neighbors (KNN)

Lazy learning: store training data, classify by majority vote of K nearest points. Non‑parametric.

from sklearn.neighbors import KNeighborsClassifier
model = KNeighborsClassifier(n_neighbors=5)

Support Vector Machines (SVM)

Finds hyperplane that maximally separates classes. Kernel trick (RBF, polynomial) for non‑linear data.

from sklearn.svm import SVC
model = SVC(kernel='rbf', C=1, gamma='scale')

Decision Trees

Recursively split data based on feature thresholds. Interpretable, prone to overfitting.

from sklearn.tree import DecisionTreeClassifier
model = DecisionTreeClassifier(max_depth=5)

Also important: Random Forest, Gradient Boosting (XGBoost, LightGBM, CatBoost), Naive Bayes.

5. Ensemble Learning

Combine multiple models to improve performance.

Bagging (Bootstrap Aggregating)

Train base models on random subsets. Reduces variance. Example: Random Forest.

from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier(n_estimators=100)

Boosting

Sequentially train weak learners, each correcting previous errors. Reduces bias. Examples: AdaBoost, Gradient Boosting, XGBoost.

from sklearn.ensemble import GradientBoostingClassifier

Stacking

Combine multiple different models via a meta‑learner.

from sklearn.ensemble import StackingClassifier

6. Clustering (Unsupervised)

K‑Means

Partition data into K clusters. Iteratively assigns points to nearest centroid, updates centroids. Sensitive to initialization (use K‑Means++).

from sklearn.cluster import KMeans
model = KMeans(n_clusters=3)
labels = model.fit_predict(X)

DBSCAN

Density‑based clustering, identifies arbitrary‑shaped clusters and noise. Parameters: eps (radius) and min_samples.

from sklearn.cluster import DBSCAN
model = DBSCAN(eps=0.5, min_samples=5)

Hierarchical Clustering

Builds tree of clusters (dendrogram). Agglomerative (bottom‑up) or divisive (top‑down).

from sklearn.cluster import AgglomerativeClustering

Evaluation: Silhouette Score, Davies‑Bouldin Index, inertia (within‑cluster sum of squares).

7. Dimensionality Reduction

PCA (Principal Component Analysis)

Finds orthogonal axes of maximum variance. Linear, unsupervised. Data must be scaled.

from sklearn.decomposition import PCA
pca = PCA(n_components=2)
X_reduced = pca.fit_transform(X_scaled)

t‑SNE

Non‑linear technique for visualization (2D/3D). Preserves local structure. Computationally heavy.

from sklearn.manifold import TSNE

UMAP

Faster, preserves more global structure. Often preferred over t‑SNE for large datasets.

Cross‑validation

K‑fold CV splits data into K folds, trains on K‑1, tests on the remaining. Provides robust performance estimate.

from sklearn.model_selection import cross_val_score
scores = cross_val_score(model, X, y, cv=5, scoring='f1')

9. Hyperparameter Tuning

Grid Search

Exhaustive search over predefined parameter grid. Uses cross‑validation.

from sklearn.model_selection import GridSearchCV
params = {'n_estimators': [50,100], 'max_depth': [3,5]}
grid = GridSearchCV(model, params, cv=5)

Random Search

Samples random combinations. More efficient for large search spaces.

from sklearn.model_selection import RandomizedSearchCV

Bayesian Optimization

Uses prior evaluations to guide search (e.g., Optuna, Hyperopt).

10. Feature Engineering & Selection

Feature creation

  • Polynomial features
  • Domain‑specific transformations (log, sqrt)
  • Interaction terms

Feature selection

  • Filter methods: correlation, chi‑square, mutual information
  • Wrapper: RFE, forward/backward selection
  • Embedded: Lasso, tree feature importance
from sklearn.feature_selection import SelectKBest, mutual_info_classif
selector = SelectKBest(mutual_info_classif, k=10)
X_new = selector.fit_transform(X, y)

11. Deep Learning Essentials

Neural Networks

Composed of layers of neurons. Each neuron computes a weighted sum of inputs, adds bias, and passes through an activation function.

  • Activation functions: ReLU, sigmoid, tanh, LeakyReLU, softmax
  • Loss functions: Cross‑Entropy (classification), MSE (regression)
  • Backpropagation: gradient computation via chain rule
  • Optimizers: SGD, Adam, RMSprop

Key architectures

  • CNN (Convolutional Neural Networks): for images
  • RNN/LSTM/GRU: sequences, time series
  • Transformer: attention‑based, used in NLP (BERT, GPT)

Regularization in DL

  • Dropout, Batch Normalization, Early Stopping, Weight Decay

12. Popular ML/DL Frameworks

Scikit‑learn

Classic ML library. Consistent API, excellent for preprocessing, classification, regression, clustering.

from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier()
model.fit(X_train, y_train)

TensorFlow / Keras

Industry‑standard for deep learning. Keras provides high‑level API.

import tensorflow as tf
model = tf.keras.Sequential([
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(10, activation='softmax')
])
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])

PyTorch

Dynamic computational graphs, popular in research. More Pythonic feel.

import torch
import torch.nn as nn
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(784, 10)
    def forward(self, x):
        return self.fc(x)
model = MyModel()

16. Best Practices & Common Pitfalls

Do

  • Always split data before preprocessing
  • Try simple models first (baseline)
  • Use cross‑validation for evaluation
  • Monitor for data drift in production
  • Keep a reproducible pipeline

Don't

  • Use test set for hyperparameter tuning
  • Ignore feature scaling for distance‑based models
  • Assume more data always helps without checking quality
  • Deploy without monitoring
Common mistakes: data leakage (using future information), overfitting to validation set, not handling class imbalance, and evaluating with only accuracy on imbalanced data.

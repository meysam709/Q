A complete remembrance‑style C reference covering syntax, data types, pointers, memory management, structs, preprocessor, file I/O, and standard library essentials with VS Code‑like syntax coloring.

1. C Basics

C is a general‑purpose, compiled language that provides low‑level memory access. It is the foundation of modern operating systems, embedded systems, and many higher‑level languages.

Key characteristics

  • Statically typed
  • Procedural paradigm
  • Manual memory management
  • Extremely portable

Common uses

  • Operating systems (Linux, Windows)
  • Embedded firmware
  • Performance‑critical applications
  • Compilers & interpreters

Compile & run (GCC)

// compile
gcc -o program main.c
// run
./program

6. Functions

/* declaration & definition */
int add(int a, int b);   // prototype

int add(int a, int b) {
    return a + b;
}

void printSum(int a, int b) {
    printf("%d\n", a + b);
}

/* recursion */
int factorial(int n) {
    return (n <= 1) ? 1 : n * factorial(n - 1);
}
Functions must be declared before use unless defined earlier. Use void for no parameters.

7. Arrays & Strings

Arrays

Strings (char arrays)

Strings are null‑terminated character arrays. Always allocate enough space for '\0'.

8. Pointers

int x = 10;
int *ptr = &x;          // pointer to x
printf("%d\n", *ptr);   // dereference: 10
*ptr = 20;             // modify x via pointer

void *vptr = &x;       // void pointer (generic)
int *iptr = (int*)vptr; // cast back

Pointer arithmetic

int arr[] = {10, 20, 30};
int *p = arr;          // pointer to first element
printf("%d\n", *(p + 1)); // 20

Function pointers

int add(int a, int b) { return a + b; }
int (*func_ptr)(int, int) = add;
int result = func_ptr(3, 4);

9. Dynamic Memory Management

#include <stdlib.h>

int *arr = (int*)malloc(5 * sizeof(int));   // allocate
if (arr == NULL) {
    /* handle error */
}
for (int i = 0; i < 5; i++) arr[i] = i;
free(arr);  // must free to avoid leaks

// zero‑initialized allocation
int *zero = (int*)calloc(5, sizeof(int));

// resize
arr = (int*)realloc(arr, 10 * sizeof(int));
Always free memory returned by malloc/calloc/realloc. Double‑free or use‑after‑free causes undefined behavior.

10. Structures & Unions

struct

struct Point {
    int x;
    int y;
};

struct Point p1 = {3, 7};
struct Point p2 = {.x = 1, .y = 2};   /* designated initializers (C99) */
printf("(%d, %d)", p1.x, p1.y);

union

union Data {
    int i;
    float f;
    char str[20];
};
union Data data;
data.i = 10;   /* only one member active at a time */
struct members are stored separately; union members share the same memory location.

13. File I/O

#include <stdio.h>

// write
FILE *fp = fopen("data.txt", "w");
if (fp != NULL) {
    fprintf(fp, "Hello, File\n");
    fclose(fp);
}

// read line by line
fp = fopen("data.txt", "r");
if (fp != NULL) {
    char line[256];
    while (fgets(line, sizeof(line), fp)) {
        printf("%s", line);
    }
    fclose(fp);
}

15. Quick Remember Tips

Strings

Always null‑terminated. Use strncpy instead of strcpy for safety.

Pointers

Initialize pointers to NULL. Check for NULL after malloc.

Arrays

Array name acts as pointer to first element. Pass array size separately.

Memory

One free per malloc. After free, set pointer to NULL.

Headers

Use include guards: #ifndef HEADER_H / #define / #endif.

Undefined behavior

Buffer overflows, signed integer overflow, and dereferencing NULL are undefined – avoid at all costs.

Common mistakes: forgetting '\0' in strings, using gets (deprecated – use fgets), mixing int and size_t, and not checking return values of malloc or fopen.

1. Python Basics

Python is a high‑level, interpreted language known for its readability and simplicity. It supports procedural, object‑oriented, and functional programming, and is widely used in web development, data science, automation, and AI.

Main features

  • Dynamically typed
  • Object‑oriented
  • Extensive standard library
  • Indentation‑based syntax

Common uses

  • Web apps (Django, Flask)
  • Data analysis (pandas, NumPy)
  • Machine Learning (TensorFlow, PyTorch)
  • Automation / scripting

Run code

# Terminal or script
python script.py

8. Object‑Oriented Programming

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"I'm {self.name}, {self.age} years old"

p = Person("Alice", 25)
print(p.introduce())

9. Inheritance & Polymorphism

class Animal:
    def speak(self):
        print("Animal sound")

class Dog(Animal):
    def speak(self):
        print("Bark")

def make_sound(animal):
    animal.speak()  # duck typing

make_sound(Dog())  # Bark
Python supports multiple inheritance. Use super() to call parent methods.

10. Error Handling

try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"Error: {e}")
else:
    print("No error occurred")
finally:
    print("Always runs")

Common built‑in exceptions: ValueError, TypeError, KeyError, FileNotFoundError.

11. File Handling

# write
with open("data.txt", "w") as file:
    file.write("Hello File")

# read
with open("data.txt", "r") as file:
    content = file.read()
    print(content)
Using with automatically closes the file, even if an exception occurs.

14. Decorators

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Took {time.time() - start}s")
        return result
    return wrapper

@timer
def slow_function():
    # ...
    pass

15. Context Managers

Used with with statement to manage setup and teardown (like files).

class ManagedResource:
    def __enter__(self):
        print("Acquiring resource")
        return self
    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Releasing resource")

with ManagedResource() as r:
    print("Using resource")

18. Quick Remember Tips

Indentation

Use 4 spaces per level. Never mix tabs and spaces.

Mutable defaults

Avoid mutable default arguments like def f(lst=[]).

Comprehensions

Prefer list/dict comprehensions over map/filter for readability.

Context managers

Always use with for files, locks, and other resources.

Error handling

Catch specific exceptions; avoid bare except:.

Virtual environments

Use venv or conda to isolate project dependencies.

Common pitfalls: modifying a list while iterating, using is to compare values (it compares identity), and forgetting that strings are immutable.

1. Java Basics

Java is a high-level, object-oriented programming language designed to be portable, secure, and platform-independent through the JVM (Java Virtual Machine). It is widely used for enterprise applications, Android development, backend systems, distributed applications, and large-scale software.

Main features

  • Object-oriented
  • Platform-independent
  • Strongly typed
  • Rich standard library

Common uses

  • Enterprise applications
  • Android apps
  • Backend systems
  • Large-scale services

Compile & run

javac Main.java
java Main

19. File Handling

Reading a file

import java.nio.file.Files;
import java.nio.file.Paths;

try {
    String content = Files.readString(Paths.get("data.txt"));
    System.out.println(content);
} catch (IOException e) {
    e.printStackTrace();
}

Writing a file

import java.nio.file.Files;
import java.nio.file.Paths;

try {
    Files.writeString(Paths.get("output.txt"), "Hello File");
} catch (IOException e) {
    e.printStackTrace();
}

Using Scanner for file input

import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

try {
    File file = new File("data.txt");
    Scanner reader = new Scanner(file);

    while (reader.hasNextLine()) {
        String line = reader.nextLine();
        System.out.println(line);
    }

    reader.close();
} catch (FileNotFoundException e) {
    e.printStackTrace();
}

20. Multithreading

Extending Thread

class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("Thread running");
    }
}

MyThread t = new MyThread();
t.start();

Implementing Runnable

class Task implements Runnable {
    @Override
    public void run() {
        System.out.println("Runnable running");
    }
}

Thread thread = new Thread(new Task());
thread.start();

Lambda thread

Thread worker = new Thread(() -> {
    System.out.println("Working in background");
});
worker.start();
Call start() to run a thread on a new call stack. Calling run() directly does not start a new thread.

21. JDBC

JDBC (Java Database Connectivity) is the standard API for connecting Java applications to relational databases.

Basic JDBC example

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;

String url = "jdbc:mysql://localhost:3306/testdb";
String user = "root";
String password = "secret";

try (
    Connection conn = DriverManager.getConnection(url, user, password);
    PreparedStatement stmt = conn.prepareStatement("SELECT * FROM users WHERE age > ?")
) {
    stmt.setInt(1, 18);

    ResultSet rs = stmt.executeQuery();

    while (rs.next()) {
        System.out.println(
            rs.getInt("id") + " " +
            rs.getString("name")
        );
    }
} catch (Exception e) {
    e.printStackTrace();
}

Common JDBC steps

  1. Load driver if needed
  2. Create connection
  3. Create statement/prepared statement
  4. Execute query or update
  5. Read result set
  6. Close resources

23. Quick Remember Tips

Class vs Object

Class is a blueprint; object is an instance of the class.

extends vs implements

extends for inheritance, implements for interfaces.

== vs equals()

== compares references for objects; equals() compares content.

Array vs ArrayList

Arrays are fixed size; ArrayList grows dynamically.

String immutability

Strings cannot be changed after creation.

Exception rule

Checked exceptions must be caught or declared with throws.

start() vs run()

start() creates a new thread; run() is a normal method call.

Stream API

Useful for expressive data processing with filter/map/collect.

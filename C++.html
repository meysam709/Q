1. C++ Basics

C++ is a high‑performance, compiled language that supports procedural, object‑oriented, and generic programming. It is widely used for systems software, game engines, real‑time applications, and performance‑critical libraries.

Main features

  • Object‑oriented
  • Strongly typed
  • Manual memory management + RAII
  • Rich Standard Template Library (STL)

Common uses

  • Operating systems
  • Game development (Unreal Engine)
  • Embedded systems
  • High‑frequency trading

Compile & run

g++ -std=c++20 -o program main.cpp
./program

9. Inheritance & Polymorphism

class Animal {
public:
    virtual void sound() const {
        std::cout << "Animal sound";
    }
    virtual ~Animal() = default;  // virtual destructor
};

class Dog : public Animal {
public:
    void sound() const override {   // 'override' keyword (C++11)
        std::cout << "Bark";
    }
};

10. Abstract Classes & Interfaces

Abstract class (pure virtual)

class Shape {
public:
    virtual double area() const = 0;  // pure virtual
    virtual ~Shape() = default;
};

class Circle : public Shape {
    double radius;
public:
    Circle(double r) : radius(r) {}
    double area() const override {
        return 3.14159 * radius * radius;
    }
};
C++ has no formal interface keyword. Use abstract classes with only pure virtual functions and a virtual destructor to mimic interfaces.

11. Encapsulation

class Student {

public:

Modern C++ often uses simple public members when no invariant is needed, but getters/setters remain common.

16. STL Algorithms

#include <algorithm>
#include <vector>
#include <numeric>

std::vector<int> nums = {1, 2, 3, 4, 5, 6};

// filter: copy_if
std::vector<int> evens;
std::copy_if(nums.begin(), nums.end(), std::back_inserter(evens),
                  [](int n) { return n % 2 == 0; });

// transform (map)
std::vector<int> squares;
std::transform(nums.begin(), nums.end(), std::back_inserter(squares),
                   [](int n) { return n * n; });

// sum
int sum = std::accumulate(nums.begin(), nums.end(), 0);
AlgorithmUse
std::copy_ifFilter elements
std::transformTransform elements
std::sortSort a range
std::find / find_ifFind an element
std::count / count_ifCount matching elements
std::accumulateSum / reduce

20. Quick Remember Tips

Classes

Use class or struct (default public). Always provide a virtual destructor for polymorphic base classes.

RAII

Acquire resources in constructors and release them in destructors. Use smart pointers instead of manual new/delete.

STL

Prefer std::vector, std::map, and std::string over C‑style arrays and char pointers.

Algorithms

Use <algorithm> functions instead of writing raw loops when possible.

Exceptions

Catch exceptions by const reference. Throw by value.

Modern C++

Embrace auto, range‑for, lambdas, and smart pointers for safer, more readable code.

Common pitfalls: forgetting virtual destructors, slicing objects, using raw new/delete, mixing signed/unsigned integers, and ignoring rule of three/five.

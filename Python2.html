10. OOP (classes/objects)

Define a class

class Car:
    def __init__(self, brand):
        self.brand = brand

    def drive(self):
        print(f"Driving {self.brand}")

c = Car("Toyota")
c.drive()

Inheritance

class Animal:
    def speak(self):
        raise NotImplementedError

class Dog(Animal):
    def speak(self):
        return "woof"

Classmethod and staticmethod

class User:
    def __init__(self, name):
        self.name = name

    @classmethod
    def from_email(cls, email):
        name = email.split("@")[0]
        return cls(name)

    @staticmethod
    def is_valid_name(name):
        return len(name) >= 2

Properties

class Circle:
    def __init__(self, r):
        self._r = r

    @property
    def radius(self):
        return self._r

    @radius.setter
    def radius(self, value):
        if value <= 0:
            raise ValueError("radius must be positive")
        self._r = value
Use @property to expose computed/validated attributes with attribute syntax.

13. Type Hints (typing)

    return 3.14159 * r * r

Common typing tools

name: Optional[str] = None

m: Dict[str, int] = {"a":1}

18. Async/Await

Basic async function

import asyncio

async def fetch_data():
    await asyncio.sleep(1)
    return "done"

async def main():
    result = await fetch_data()
    print(result)

asyncio.run(main())

Concurrent tasks

async def work(n):
    await asyncio.sleep(1)
    return n * 2

async def main():
    results = await asyncio.gather(
        work(1),
        work(2),
        work(3)
    )
    print(results)
async/await is for cooperative concurrency, especially I/O-bound tasks, not raw CPU-bound parallelism.

22. Quick Remember Tips

Indentation matters

Whitespace defines blocks instead of braces.

Mutable defaults

Avoid defaults like []; use None and create inside.

is vs ==

== compares values; is compares identity.

List vs tuple

Lists are mutable; tuples are immutable.

Dict order

Modern Python preserves insertion order in dictionaries.

Everything is object-based

Functions, classes, and modules are all first-class objects.

Generators save memory

Use yield and generator expressions for lazy evaluation.

Async is for I/O

Best for network/file waiting, not heavy CPU work.

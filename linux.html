Linux/Unix – The Complete Reference

An ultra‑comprehensive guide to Linux and Unix: commands, filesystem, processes, permissions, networking, shell scripting, package management, and more. Designed for learners, system administrators, and power users.

1. Linux/Unix Fundamentals

Linux is a Unix‑like, open‑source operating system kernel used by countless distributions (Ubuntu, Fedora, Arch, etc.). The command line interface (shell) is the most powerful way to interact with the system.

Key characteristics

  • Multi‑user, multi‑tasking
  • Hierarchical filesystem
  • Everything is a file
  • Extensive CLI tools

Common shells

  • Bash (Bourne Again SHell)
  • Zsh, Fish, Ksh
  • Default prompt: user@host:~$

First commands

whoami       # show current user
pwd          # print working directory
ls           # list files
date         # show date/time

3. File Operations

Create & view

touch file.txt         # create empty file
mkdir newdir           # create directory
mkdir -p a/b/c       # create nested dirs
cat file               # display entire file
less file              # view with scrolling
head -n 5 file     # first 5 lines
tail -f log           # follow log file

Copy, move, delete

cp src dest          # copy file
cp -r src/ dest/    # copy directory recursively
mv old new           # move / rename
rm file               # delete file
rm -rf dir/         # force delete directory (danger!)
Double‑check rm -rf commands; there is no recycle bin.

4. File Permissions & Ownership

Every file has an owner, a group, and three permission triads: r (read), w (write), x (execute).

ls -l
# output: -rwxr-xr-- 1 alice staff 4096 Jan 1 12:00 script.sh

Permission bits

  • User (u): owner
  • Group (g): group members
  • Others (o): everyone else

chmod

chmod u+x file        # add execute for owner
chmod 755 script        # numeric: rwxr-xr-x
chmod -R 644 dir/      # recursive, files become rw-r--r--

chown, chgrp

chown user:group file
chgrp group file

5. Text Processing & Pipes

Unix excels at combining simple tools via pipes (|) to process text streams.

grep

grep "pattern" file
grep -r "text" dir/       # recursive
grep -i "TEXT" file    # ignore case
grep -v "pattern" file # invert match

sed

sed 's/old/new/' file      # replace first occurrence
sed -i 's/old/new/g' file # in‑place replace all
sed -n '5,10p' file       # print lines 5‑10

awk

awk '{print $1, $3}' file   # columns 1 & 3
awk -F: '{print $1}' /etc/passwd

Other essentials

sort file             # sort lines
uniq file             # remove duplicate lines
wc -l file          # line count
tee file             # write to stdout and file
cut -d: -f1 file   # extract fields

6. I/O Redirection

OperatorMeaning

command >> fileAppend stdout
command 2> fileRedirect stderr

Viewing processes

Controlling processes

kill PID                # send SIGTERM (graceful)

pkill -f pattern       # kill by pattern
bg                      # resume job in background

Background execution

command &               # run in background
nohup command &         # keep running after logout

13. Shell Scripting (Bash)

Basic script

#!/bin/bash
# my_script.sh
echo "Hello, $USER"
echo "Today is $(date)"
read -p "Enter name: " name
echo "Hi $name"

Variables & conditionals

var="value"         # no spaces around =
readonly VAR=10
if [ $x -gt 10 ]; then
    echo "Greater"
elif [ $x -eq 10 ]; then
    echo "Equal"
else
    echo "Less"
fi

Loops

for i in {1..5}; do echo $i; done
for file in *.txt; do echo "Processing $file"; done
while [ $x -lt 10 ]; do ((x++)); done

Functions

function greet {
    echo "Hello, $1"
}
greet "Alice"

14. Task Scheduling (cron)

Cron jobs run at scheduled times. Each user has a crontab.

# Edit crontab
crontab -e
# Format: min hour day month weekday command
0 2 * * * /path/to/backup.sh   # daily at 2 AM
*/5 * * * * command                 # every 5 minutes

Use @reboot to run at startup. System‑wide cron: /etc/crontab and /etc/cron.*/ directories.

15. Service Management (systemd)

systemctl status sshd          # check service
sudo systemctl start nginx     # start service
sudo systemctl enable nginx    # enable at boot
sudo journalctl -u nginx     # view service logs

Older SysV init: service sshd restart, chkconfig.

16. Environment Variables

Persistent settings go in ~/.bashrc, ~/.profile, or /etc/environment.

18. Terminal Shortcuts & History

Bash shortcuts

  • Ctrl+C – kill foreground process
  • Ctrl+D – end of input (exit shell)
  • Ctrl+Z – suspend foreground job
  • Ctrl+R – search command history
  • !! – re‑run last command
  • Ctrl+L – clear screen

Command history

history              # show command history
history | grep "pattern"
!N                # execute command number N
!!                # repeat last command
!$                # last argument of previous command

21. Final Tips & Best Practices

Good habits

  • Use man for command help
  • Create aliases for frequent commands
  • Back up config files before editing
  • Keep system updated

Danger zones

  • Avoid rm -rf / or rm -rf * without checking
  • Don't run scripts from untrusted sources as root
  • Be careful with chmod -R 777
Common pitfalls: forgetting sudo, misplacing spaces in variable assignments, using rm -rf with a variable that might be empty, and not quoting variables containing spaces.

A complete remembrance‑style JavaScript reference covering syntax, data types, functions, OOP, DOM, events, async patterns, and modern ES6+ essentials with VS Code‑like syntax coloring.

1. JavaScript Basics

JavaScript is a high‑level, interpreted language that powers dynamic behavior on the web. It supports event‑driven, functional, and object‑oriented programming styles, and runs both in the browser and on the server (Node.js).

Main features

  • Dynamic typing
  • Prototype‑based OOP
  • First‑class functions
  • Event‑driven & asynchronous

Common uses

  • Front‑end web (React, Vue, etc.)
  • Back‑end (Node.js)
  • Mobile apps (React Native)
  • Desktop apps (Electron)

8. OOP: Prototypes & Classes

Constructor function (pre‑ES6)

function Car(brand, year) {
    this.brand = brand;
    this.year = year;
}
Car.prototype.drive = function() {
    console.log(`${this.brand} is driving`);
};

ES6 Class

class Car {
    constructor(brand, year) {
        this.brand = brand;
        this.year = year;
    }
    drive() {
        console.log(`${this.brand} is driving`);
    }
}
const car = new Car("Toyota", 2023);

9. Inheritance & Prototype Chain

class Animal {
    speak() {
        console.log("Animal sound");
    }
}

class Dog extends Animal {
    speak() {
        console.log("Bark");
    }
}

const d = new Dog();
d.speak();  // "Bark"
Use extends and super to call parent constructor/methods.

12. Closures & Scope

function createCounter() {
    let count = 0;
    return function() {
        return ++count;  // retains access to 'count'
    };
}
const counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2

Variables declared with let and const are block‑scoped; var is function‑scoped.

14. Async / Await

async function fetchData() {
    const response = await fetch("https://api.example.com");
    const data = await response.json();
    return data;
}
const result = await fetchData();  // inside async context
Always wrap await in a try/catch or handle errors with .catch().

18. Quick Remember Tips

Variables

Use const by default, let when reassignment is needed. Avoid var.

Functions

Arrow functions inherit this from the surrounding context; use regular functions when you need dynamic this.

Arrays

Use map, filter, reduce instead of loops for clarity.

Async

Prefer async/await over raw promises for better readability.

DOM

Cache DOM references; avoid querying inside loops.

Errors

Always handle promise rejections (either .catch() or try/catch with await).

Common mistakes: using == instead of ===, forgetting this binding in callbacks, mutating objects/arrays passed as props, and ignoring async error handling.

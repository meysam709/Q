1. C# Basics

C# is a modern, object-oriented programming language developed by Microsoft. It is widely used for desktop applications, web APIs, enterprise software, game development with Unity, and cloud applications using .NET.

Main features

  • Object-oriented
  • Strongly typed
  • Managed by .NET runtime
  • Rich standard library

Common uses

  • ASP.NET web applications
  • Desktop apps
  • Unity game development
  • Backend services

Compile & run

// using dotnet CLI
dotnet run

10. Abstract Classes & Interfaces

Abstract class

abstract class Shape
{
    public abstract double Area();
}

class Circle : Shape
{
    public double Radius;

    public override double Area()
    {
        return Math.PI * Radius * Radius;
    }
}

Interface

interface IFlyable
{
    void Fly();
}

class Bird : IFlyable
{
    public void Fly()
    {
        Console.WriteLine("Bird is flying");
    }
}

21. Quick Remember Tips

Classes

Use classes to model objects with fields, properties, and methods.

Properties

Prefer properties over manual getter/setter methods.

Collections

Use List<T>, Dictionary<K,V>, and HashSet<T>.

LINQ

Use LINQ for filtering, transforming, sorting, and aggregating data.

Exceptions

Wrap risky code in try/catch.

Async

Use async/await for non-blocking operations.

Common mistakes: forgetting semicolons, confusing fields with properties, not checking for null, and ignoring async task handling.

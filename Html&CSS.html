HTML & CSS Complete Summary

A complete remembrance‑style reference for HTML and CSS covering structure, semantics, forms, selectors, box model, layout, responsive design, and modern features.

1. HTML Basics

HTML (HyperText Markup Language) provides the structure of web pages. It uses tags to define elements like headings, paragraphs, images, and links. HTML5 introduced semantic elements and multimedia support.

Key characteristics

  • Markup language (not programming)
  • Elements defined by tags
  • Hierarchical (DOM tree)
  • Case‑insensitive tags

Common uses

  • Web page structure
  • Content markup
  • Forms & user input
  • SEO & accessibility

Basic structure

<!DOCTYPE html>
<html>
<head>...</head>
<body>...</body>
</html>

2. HTML Document Structure

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Page Title</title>
    <link rel="stylesheet" href="styles.css" />
</head>
<body>
    <h1>Hello, World!</h1>
    <script src="script.js"></script>
</body>
</html>
The <meta name="viewport"> is essential for responsive design.

10. CSS Basics

CSS (Cascading Style Sheets) controls the presentation of HTML. It can be applied inline, internally via <style>, or externally via <link>. 

/* syntax: selector { property: value; } */
h1 {
    color: blue;
    font-size: 2rem;
}
CSS follows the cascade: more specific selectors and later rules override earlier ones.

11. CSS Selectors

/* basic selectors */
p { }               /* element */
.class { }            /* class */
#id { }               /* id */
* { }                 /* universal */

/* combinators */
div p { }           /* descendant */
div > p { }         /* child */
div + p { }         /* adjacent sibling */
div ~ p { }         /* general sibling */

/* pseudo‑classes */
a:hover { }
input:focus { }
li:first-child { }

/* pseudo‑elements */
p::first-line { }
div::before { content: "↑"; }

12. Box Model

div {
    width: 300px;
    height: 150px;
    padding: 20px;           /* inner spacing */
    border: 2px solid black; /* border */
    margin: 10px auto;       /* outer spacing (auto centers) */
    box-sizing: border-box;  /* include border/padding in width */
}
Using box-sizing: border-box globally makes layout predictable.

15. Layout: Flexbox

.container {
    display: flex;
    flex-direction: row;          /* row | column | row-reverse ... */
    justify-content: space-between; /* main axis */
    align-items: center;          /* cross axis */
    gap: 20px;
}
.item {
    flex: 1;  /* grow evenly */
    align-self: stretch;
}

Flexbox cheatsheet

PropertyValuesEffect
justify-contentflex-start, center, space-between, space-aroundMain axis alignment
align-itemsflex-start, center, stretchCross axis alignment
flex-wrapnowrap, wrapWrap items
flex-grow0 (default) or positive numberGrow factor

16. Layout: CSS Grid

.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);  /* three equal columns */
    grid-template-rows: 100px auto;
    gap: 16px;   /* shorthand for row-gap and column-gap */
}
.item {
    grid-column: span 2;   /* span across columns */
    grid-row: 1 / 3;     /* from row line 1 to 3 */
}
Grid is ideal for 2‑dimensional layouts; Flexbox is better for 1‑dimensional rows or columns.

17. Responsive Design

/* media queries */
@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

/* fluid images */
img {
    max-width: 100%;
    height: auto;
}

/* responsive units */
font-size: clamp(1rem, 2.5vw, 2rem);  /* min, preferred, max */

18. Transitions & Animations

/* transition */

    background: blue;
    transition: background 0.3s ease;
}

}

/* keyframe animation */
@keyframes slideIn {
    from { transform: translateX(-100%); }
    to   { transform: translateX(0); }

    animation: slideIn 0.5s ease-out;
}

19. Modern CSS Features

CSS Variables

:root {
    --main-color: #3498db;
}
body { color: var(--main-color); }

Flexbox Gap

gap: 20px; works in flex and grid without margin hacks.

Aspect Ratio

aspect-ratio: 16 / 9;

Container Queries

Style based on parent container size, not viewport.

20. Quick Remember Tips

HTML

  • Always include <!DOCTYPE html>
  • Use semantic tags for accessibility
  • Close all tags (XHTML style optional but clean)
  • Forms need name attributes for submission

CSS

  • Use box-sizing: border-box globally
  • Prefer rem / em over px for typography
  • Organize with a methodology (BEM, utility‑first)
  • Minimize repaints by animating transform and opacity
Common pitfalls: forgetting the viewport meta tag, overusing !important, not clearing floats, ignoring cross‑browser compatibility, and missing alt text on images.

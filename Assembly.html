Assembly (x86-64) Complete Summary

A comprehensive remembrance‑style reference for x86‑64 Assembly (Intel syntax). Covers registers, instructions, memory addressing, control flow, the stack, system calls, and essential patterns – with full code examples.

1. Assembly Basics

Assembly is a low‑level language that maps directly to machine code. x86‑64 (also called AMD64) is the 64‑bit extension of the x86 architecture. It uses little‑endian byte ordering and supports a large register set.

Key characteristics

  • Each instruction corresponds to one CPU operation
  • Register‑based (load/store architecture)
  • Little‑endian
  • Supports multiple addressing modes

Common assemblers

  • NASM (Netwide Assembler)
  • MASM (Microsoft Macro Assembler)
  • GAS (GNU Assembler, AT&T syntax)

Assemble & link (NASM)

; assemble
nasm -f elf64 -o program.o program.asm
; link
ld -o program program.o

3. Registers (x86-64)

64‑bit registers start with R. Lower parts are accessible as E (32‑bit), W (16‑bit), and B/L (8‑bit).

Special registers

  • RIP – Instruction pointer (cannot be modified directly)
  • RFLAGS – Status flags (CF, ZF, SF, OF, etc.)
  • XMM0–XMM15 – 128‑bit SSE registers (floating point)

4. Data Directives & Types

section .data
    byte_var  db 0x55              ; define byte (8 bits)
    word_var  dw 1000             ; define word (16 bits)
    dword_var dd 0x12345678       ; define double word (32 bits)
    qword_var dq 0x1A2B3C4D5E6F   ; define quad word (64 bits)
    ten_bytes dt 3.14            ; define ten bytes (80‑bit float)
    str_var   db "Hello", 0      ; null‑terminated string
    array     dd 1, 2, 3, 4     ; array of dwords

section .bss
    buffer resb 256        ; reserve 256 bytes
    arr    resq 10         ; reserve 10 quad words
Data is laid out sequentially in memory. Strings are not automatically null‑terminated unless you add , 0.

5. Memory Addressing Modes

General form: [base + index*scale + displacement]

mov rax, [rbx]               ; base only
mov rax, [rbx + 8]          ; base + displacement
mov rax, [rbx + rcx*4]     ; base + index*scale
mov rax, [rbx + rcx*4 + 16] ; full form
mov rax, [array]          ; direct address (label)
mov rax, [array + rcx*4] ; label + offset

Scale can be 1, 2, 4, or 8. Displacement can be 8, 16, or 32 bits.

Always ensure the address is valid and the size matches the destination register.

6. Data Movement Instructions

mov rax, 42                ; immediate to register
mov rax, rbx               ; register to register
mov rax, [rbx]            ; memory to register
mov [rbx], rax             ; register to memory

movzx rax, byte [rsi]  ; move with zero‑extend
movsx rax, word [rsi]  ; move with sign‑extend

lea rax, [rbx + 8]       ; load effective address (no memory access)

push rax                    ; push onto stack (RSP -= 8)
pop rbx                     ; pop from stack (RSP += 8)

7. Arithmetic & Logic

add rax, 10            ; rax += 10
sub rbx, rcx           ; rbx -= rcx
inc rax                 ; rax++
dec rax                 ; rax--
mul rbx                 ; unsigned: rdx:rax = rax * rbx
imul rax, rbx, 3   ; signed: rax = rbx * 3
div rcx                 ; unsigned: rax = rdx:rax / rcx, rdx = remainder
idiv rcx                ; signed division

and rax, rbx           ; bitwise AND
or  rax, rbx           ; bitwise OR
xor rax, rax          ; zero out rax (xor same = 0)
not rax                 ; bitwise NOT
neg rax                 ; two's complement negation
shl rax, 1            ; logical shift left (multiply by 2)
shr rax, 1            ; logical shift right
sar rax, 1            ; arithmetic shift right (preserve sign)
Flags (ZF, CF, SF, OF) are set by most arithmetic instructions. Use cmp to set flags without storing the result.

8. Control Flow

Unconditional jumps

jmp label          ; direct jump
jmp rax            ; indirect jump (register)

Conditional jumps (after cmp or arithmetic)

cmp rax, rbx
je  equal          ; jump if equal (ZF=1)
jne not_equal     ; jump if not equal (ZF=0)
jg  greater       ; jump if greater (signed)
jl  less          ; jump if less (signed)
ja  above         ; jump if above (unsigned)
jb  below         ; jump if below (unsigned)
jz  zero_flag     ; same as je

Loops

mov rcx, 10
loop_start:
    ; body
    dec rcx
    jnz loop_start

; or use 'loop' instruction (decrements rcx and jumps if not zero)
mov rcx, 5
l1:
    loop l1

9. Stack & Functions

Stack basics

push rbp          ; save old base pointer
mov rbp, rsp     ; set new base pointer
sub rsp, 32      ; allocate 32 bytes for locals
; ... function body ...
mov rsp, rbp     ; restore stack pointer
pop rbp           ; restore old base pointer
ret               ; return (pops RIP)

Calling a function

call my_function   ; pushes return address and jumps
; after call, rax holds return value (if any)

Calling convention (System V AMD64 ABI)

  • First 6 integer/pointer arguments: RDI, RSI, RDX, RCX, R8, R9
  • Return value: RAX
  • Callee‑saved registers: RBX, RBP, R12–R15
  • Stack must be 16‑byte aligned before call

10. System Calls (Linux x86-64)

mov rax, 1            ; syscall number (write)
mov rdi, 1            ; arg1: file descriptor (stdout)
mov rsi, msg         ; arg2: pointer to string
mov rdx, 13           ; arg3: length
syscall               ; invoke kernel
; return value in rax
syscallraxrdirsirdx
read0fdbufcount
write1fdbufcount
open2filenameflagsmode
close3fd--
exit60error_code--
Arguments go in: RDI, RSI, RDX, R10, R8, R9. Use syscall instruction (not int 0x80).

12. Floating Point (SSE)

; Scalar double‑precision
movsd xmm0, [rsi]       ; load double
addsd xmm0, xmm1         ; add doubles
movsd [rdi], xmm0       ; store double

; Scalar single‑precision
movss xmm0, [rsi]
mulss xmm0, xmm1

; Convert between integers and floats
cvtsi2sd xmm0, rax   ; integer to double
cvttsd2si rax, xmm0 ; truncate double to integer

13. Common Patterns

Zero a register

xor rax, rax

Set to 1

xor rax, rax
inc rax

Swap two registers

xchg rax, rbx

Load address of string

lea rsi, [msg]

Multiply by constant

lea rax, [rax + rax*4]  ; rax *= 5

String length (loop)

mov rdi, msg
xor al, al
mov rcx, -1
repne scasb        ; find zero byte

14. Quick Remember Tips

Registers

Learn the ABI: RDI, RSI, RDX, RCX, R8, R9 for args; RAX return; RBX, RBP, R12‑R15 preserved.

Instructions

Most instructions can take register, memory, or immediate operands. Destination usually first (Intel).

Stack alignment

Keep stack 16‑byte aligned before calls. Sub an odd multiple of 8 if needed.

Comments

Use ; for comments. Document registers and side effects.

Debugging

Use gdb with layout asm, stepi, info registers.

Endianness

Little‑endian: least significant byte at lowest address.

Common pitfalls: forgetting to zero a register before division, using wrong operand size, not aligning the stack, and corrupting callee‑saved registers.

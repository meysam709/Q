Django Backend Complete Guide

A teaching‑oriented, complete guide to backend development with Django. Covers MVT architecture, models, ORM, views, templates, forms, admin, authentication, REST APIs (DRF), testing, and deployment.

1. Django Fundamentals

Django is a high‑level Python web framework that encourages rapid development and clean, pragmatic design. It follows the Model‑View‑Template (MVT) pattern: Models handle data, Views contain logic, and Templates render the user interface. Django comes with an ORM, admin panel, authentication, and many built‑in features.

Core components

  • Models (database schema)
  • Views (request handlers)
  • Templates (HTML rendering)
  • URL dispatcher
  • Admin interface

Start a project

# install Django
pip install django

# create project
django-admin startproject myproject

# run development server
python manage.py runserver

Project structure

myproject/
├── manage.py
├── myproject/
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   └── wsgi.py

2. Apps & URL Routing

A Django project is composed of multiple apps. Each app is a self‑contained module.

# create an app
python manage.py startapp blog

App structure: models.py, views.py, urls.py (create it), templates/, etc.

URL configuration

# myproject/urls.py
from django.urls import include, path

urlpatterns = [
    path('blog/', include('blog.urls')),
]

# blog/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path('', views.home, name='blog-home'),
    path('post/<int:pk>/', views.post_detail, name='post-detail'),
]
Use <int:pk> to capture URL parameters and pass them to views.

3. Models & the ORM

Models are Python classes that map to database tables. Each attribute represents a database field.

from django.db import models

class Post(models.Model):
    title = models.CharField(max_length=200)
    slug = models.SlugField(unique=True)
    body = models.TextField()
    created = models.DateTimeField(auto_now_add=True)
    author = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE)

    class Meta:
        ordering = ['-created']

    def __str__(self):
        return self.title

Migrations

python manage.py makemigrations    # create migration files
python manage.py migrate           # apply to database

Query examples

# all posts
Post.objects.all()

# filter
Post.objects.filter(author=user, title__icontains='django')

# get single object
Post.objects.get(pk=1)  # raises DoesNotExist if not found

# eager loading
Post.objects.select_related('author').all()

4. Views – Function & Class‑Based

Function‑based view

from django.shortcuts import render, get_object_or_404
from .models import Post

def post_list(request):
    posts = Post.objects.all()
    return render(request, 'blog/post_list.html', {'posts': posts})

Class‑based generic views

from django.views.generic import ListView, DetailView
from .models import Post

class PostListView(ListView):
    model = Post
    template_name = 'blog/post_list.html'
    context_object_name = 'posts'

class PostDetailView(DetailView):
    model = Post
    template_name = 'blog/post_detail.html'

URL configuration with CBVs uses .as_view().

5. Templates & Static Files

Django uses its own template language. Create templates inside blog/templates/blog/.

<!-- base.html -->
<!DOCTYPE html>
<html>
<head><title>{% block title %}My Blog{% endblock %}</title></head>
<body>
    {% block content %}{% endblock %}
</body>
</html>

<!-- post_list.html -->
{% extends 'blog/base.html' %}
{% block content %}
    {% for post in posts %}
        <h2><a href="{% url 'post-detail' post.pk %}">{{ post.title }}</a></h2>
    {% endfor %}
{% endblock %}

Static files

Store CSS/JS/images in blog/static/blog/. Load with {% load static %}.

{% load static %}
<link rel="stylesheet" href="{% static 'blog/style.css' %}" />

6. Forms & ModelForms

Forms handle user input and validation. ModelForms automatically create forms from models.

from django import forms
from .models import Post

class PostForm(forms.ModelForm):
    class Meta:
        model = Post
        fields = ['title', 'body']

View to handle form:

def post_create(request):
    if request.method == 'POST':
        form = PostForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('blog-home')
    else:
        form = PostForm()
    return render(request, 'blog/post_form.html', {'form': form})

7. The Django Admin

A built‑in interface for managing data. Register models in admin.py.

from django.contrib import admin
from .models import Post

@admin.register(Post)
class PostAdmin(admin.ModelAdmin):
    list_display = ['title', 'author', 'created']
    prepopulated_fields = {'slug': ('title',)}
    search_fields = ['title', 'body']

Create a superuser: python manage.py createsuperuser. Access admin at /admin/.

8. Authentication & Authorization

Django provides a full authentication system with users, groups, and permissions.

# login required decorator
from django.contrib.auth.decorators import login_required

@login_required
def dashboard(request):
    return render(request, 'dashboard.html')

Built‑in views: LoginView, LogoutView, PasswordChangeView. Add to urls:

from django.contrib.auth import views as auth_views
urlpatterns += [
    path('accounts/login/', auth_views.LoginView.as_view(), name='login'),
]

9. Django REST Framework (DRF)

DRF is the standard toolkit for building Web APIs with Django. Install with pip install djangorestframework.

Serializers

from rest_framework import serializers
from .models import Post

class PostSerializer(serializers.ModelSerializer):
    class Meta:
        model = Post
        fields = ['id', 'title', 'body', 'author', 'created']

Viewsets & Routers

from rest_framework import viewsets
from .models import Post
from .serializers import PostSerializer

class PostViewSet(viewsets.ModelViewSet):
    queryset = Post.objects.all()
    serializer_class = PostSerializer

URLs with router:

from rest_framework.routers import DefaultRouter
router = DefaultRouter()
router.register('posts', PostViewSet)
urlpatterns += router.urls

Add 'rest_framework' to INSTALLED_APPS.

10. Testing in Django

Django uses Python's built‑in unittest with extensions. Test files live in tests.py or a tests/ package.

from django.test import TestCase
from .models import Post

class PostModelTest(TestCase):
    def test_string_representation(self):
        post = Post(title="Test")
        self.assertEqual(str(post), "Test")

Run tests: python manage.py test.

11. Deployment Considerations

Settings

  • Set DEBUG = False
  • Use environment variables for SECRET_KEY, database URL
  • Allow only your domain in ALLOWED_HOSTS

Static & Media

Collect static files with python manage.py collectstatic. Serve from a web server (Nginx, etc.) or a CDN.

Database

Use PostgreSQL for production. Apply migrations as part of your deploy process.

Web server

Gunicorn / uWSGI behind Nginx is a common setup. Use HTTPS.

12. Best Practices & Quick Tips

Project structure

Keep apps modular. Use a config or core app for common models.

Query efficiency

Use select_related / prefetch_related to avoid N+1 queries.

Security

Always use CSRF protection. Escape user input in templates (auto‑escaped). Use django‑axes for brute‑force protection.

Environment variables

Use python‑decouple or django‑environ to manage settings.

Common pitfalls: forgetting to run migrations, not handling DoesNotExist exceptions, using CharField without max_length, and leaving DEBUG=True in production.

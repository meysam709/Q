PHP Complete Guide

A teaching‑oriented, comprehensive guide to PHP. Covers syntax, variables, functions, arrays, OOP, database access (PDO), forms, sessions, and modern PHP features.

1. PHP Fundamentals

PHP is a server‑side scripting language designed for web development. It is embedded within HTML and runs on a web server (Apache, Nginx). PHP is dynamically typed, has a large standard library, and powers millions of websites.

Key characteristics

  • Server‑side execution
  • Embedded in HTML
  • Dynamic typing
  • Huge ecosystem (Composer, frameworks)

Common uses

  • Dynamic websites
  • Content Management Systems (WordPress)
  • REST APIs
  • E‑commerce platforms

First script

<?php
echo "Hello, PHP!";
?>

2. Syntax & Structure

<?php
// PHP code goes here
$name = "Alice";
echo "Hello, $name!";   // variables inside double quotes
?>

Comments

// single‑line comment
# also single‑line (less common)
/* multi‑line
   comment */
PHP files usually have .php extension. The closing ?> is optional if the file contains only PHP.

5. Control Flow

    echo "Adult";
} elseif ($age >= 13) {

    echo "Child";

switch

    case 1: echo "Monday"; break;
    default: echo "Unknown";
}

Loops

    echo $i;
}

foreach ($items as $item) {
    echo $item;

6. Functions

function add($a, $b) {
    return $a + $b;
}

// type declarations (PHP 7+)
function multiply(int $a, int $b): int {
    return $a * $b;
}

// arrow function (PHP 7.4+)
$double = fn($x) => $x * 2;

// variable‑length argument lists
function sum(...$nums) {
    return array_sum($nums);
}

7. Arrays

Indexed & associative arrays

$indexed = ['apple', 'banana'];
$assoc = ['name' => 'Alice', 'age' => 25];

echo $indexed[0];         // apple
echo $assoc['name'];      // Alice

Array functions

count($arr);               // length
array_push($arr, 'new');   // add to end
array_pop($arr);            // remove last
array_merge($a, $b);      // merge arrays
array_filter($arr, $callback);
array_map($callback, $arr);

8. Strings

$str = "Hello";
echo strlen($str);           // 5
echo strtoupper($str);      // HELLO
echo str_replace('H', 'J', $str); // Jello
$pos = strpos($str, 'll');  // 2

Use sprintf() or double‑quoted strings with variable interpolation for complex formatting.

9. Object‑Oriented Programming

Classes & objects

class Person {
    public $name;
    private $age;

    function __construct($name, $age) {
        $this->name = $name;
        $this->age = $age;
    }

    public function introduce() {
        return "I'm $this->name, $this->age years old.";
    }
}

$p = new Person("Alice", 25);
echo $p->introduce();

Inheritance & polymorphism

class Animal {
    public function speak() {
        return "Animal sound";
    }
}

class Dog extends Animal {
    public function speak() {
        return "Bark";
    }
}

Interfaces & traits

interface Logger {
    public function log($msg);
}

trait Timestampable {
    public $created_at;
    public function setCreatedAt($date) {
        $this->created_at = $date;
    }
}

10. Error & Exception Handling

try {
    $result = 10 / 0;
    if (!$result) {
        throw new Exception("Division by zero");
    }
} catch (Exception $e) {
    echo "Error: " . $e->getMessage();
} finally {
    echo "Cleanup";
}

PHP 8+ uses \Error for internal errors and \Exception for user exceptions. Both implement Throwable.

11. File Handling

// read entire file
$content = file_get_contents('data.txt');

// write to file
file_put_contents('data.txt', 'Hello');

// fopen / fwrite / fclose (for streaming)
$handle = fopen('log.txt', 'a');
fwrite($handle, "New line\n");
fclose($handle);
Always check if the file exists and is readable/writable before operations. Use is_readable(), is_writable().

12. Database Access with PDO

PDO (PHP Data Objects) provides a consistent interface for multiple databases.

$dsn = 'mysql:host=localhost;dbname=test;charset=utf8mb4';
$user = 'root';
$pass = '';

try {
    $pdo = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    ]);

    // prepared statement
    $stmt = $pdo->prepare('SELECT * FROM users WHERE id = ?');
    $stmt->execute([$id]);
    $user = $stmt->fetch(PDO::FETCH_ASSOC);
} catch (PDOException $e) {
    echo "DB error: " . $e->getMessage();
}
Never concatenate user input directly into SQL queries. Always use prepared statements to prevent SQL injection.

13. Handling Forms

// check if form submitted
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $name = htmlspecialchars($_POST['name'] ?? '');
    $email = filter_input(INPUT_POST, 'email', FILTER_VALIDATE_EMAIL);
    if (!$email) {
        $error = "Invalid email";

Superglobals: $_GET, $_POST, $_FILES (file uploads), $_SESSION, $_COOKIE.

16. Quick Tips & Best Practices

Security

  • Always escape output with htmlspecialchars()
  • Use prepared statements for database queries
  • Hash passwords with password_hash()
  • Validate all user input

Performance

  • Use single quotes for static strings
  • Enable opcode caching (OPcache)
  • Autoload classes with Composer

Code style

  • Follow PSR‑12 coding standards
  • Use meaningful variable names
  • Keep functions short and focused
Common pitfalls: trusting user input without validation, using == instead of ===, forgetting to start the session, and using mysql_* functions (removed in PHP 7).
